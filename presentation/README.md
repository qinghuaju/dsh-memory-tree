# dsh-memory-tree · 讲解演示（纸本档案 · B 风格）

## 打开方式

直接双击 `index.html`（离线、无 CDN、无构建）。建议全屏 1920×1080 录制。

## 操作

| 按键 | 作用 |
|---|---|
| `←` / `→` / `空格` | 上一页 / 下一页 |
| `Home` / `End` | 第一页 / 最后一页 |
| `F` | 全屏 |
| `H` | 隐藏/显示底部控制条（录制时建议隐藏） |
| 鼠标移到左右边缘并点击 | 上一页 / 下一页 |
| 地址栏 `#3` | 直接跳到第 3 页（可做分镜链接） |

## 动效

- **入场**：元素按 DOM 顺序交错 65ms，`下移 15px + 淡入 + 去模糊`；SVG 节点分级弹出，折线与连线用描边绘制，数字滚动；
- **退场**：换页前反向交错 38ms，`上移 13px + 淡出 + 模糊`，全部结束后再切页；
- **图表**：预算条从 0 伸展，折线按 `stroke-dashoffset` 绘制；
- **降级**：系统开启“减少动态效果”时，全部改为即时显示（`prefers-reduced-motion`）。

## 改内容

所有文字都在 `index.html` 里直接改：

- 页码：`<span class="pn">01 / 14</span>`；
- 每页标题：`<h2>`；强调词用 `<em>`（自动朱红）；
- 数字（第 12 页）：`data-count="11.6"`，进入页面时自动滚动；
- 新页面：复制一个 `<section class="slide" data-title="...">`，加在 `.stage` 里，底部页码与 HUD 会自动适配。

改文案后不需要构建，刷新即可。**换页动效只依赖 `.a` / `.a-fade` 类**，包裹即可获得入场/退场。

## 加 AI 氛围图（可选）

按照 `DESIGN.md` 第六节的 B 风格提示词生成（risograph、暖纸、朱红/墨绿、no text），放到 `presentation/assets/`，然后在对应页加：

```html
<div class="a" style="position:absolute;inset:0;z-index:-1;overflow:hidden">
  <img src="assets/b1-cover.webp" alt="" style="width:100%;height:100%;object-fit:cover;opacity:.35" />
</div>
```

注意：**信息图不要用 AI 图**；文字、路径、公式一律保留为 HTML/SVG。

## 录制建议

- 分辨率 1920×1080，全屏，隐藏鼠标与底部控制条（`H`）；
- 每页停留 20–40 秒讲解；翻页前留 0.5 秒让退场动画完成；
- 第 9、11、12 页信息密度高，建议分两段讲：先讲结论，再讲参数；
- 若需要 GIF/视频，用 OBS 录屏即可；本页无网络依赖，断网也能放。
